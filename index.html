Deploy Your App to EigenCompute

Step-by-step guide to go from zero to a live app running inside an Intel TDX Trusted Execution Environment on EigenCompute. No prior EigenCloud experience needed.

What is EigenCompute?

EigenCompute is a verifiable compute platform by EigenLayer. You give it a Docker image, it runs your app inside an Intel TDX Trusted Execution Environment (TEE) — meaning your code and data are protected even from the host machine. Every execution can be cryptographically attested on-chain.

Prerequisites

Make sure you have these installed before starting. If you don't have them yet, follow the links to set them up.

  • Docker Desktop — must have buildx enabled (included by default in Docker Desktop 4.x+)
  • Node.js 20+ — or whatever runtime your app uses
  • Docker Hub account — to push your container image (free tier works)
  • An Ethereum wallet — you'll need a private key to authenticate with EigenCompute. You can generate one during setup, or use an existing one from MetaMask

Step 1 — Install the ecloud CLI

The ecloud CLI is the command-line tool that manages everything — authentication, billing, deployment, logs, upgrades. Install it with a single command:

curl -fsSL https://raw.githubusercontent.com/Layr-Labs/eigencloud-tools/master/install-all.sh | bash

Source: github.com/Layr-Labs/eigencloud-tools

Verify it installed correctly:

ecloud version
# Should output something like: Version: 0.3.4
💡 If ecloud is not found after install, restart your terminal or run source ~/.bashrc / source ~/.zshrc.

Step 2 — Authenticate

EigenCompute uses an Ethereum private key for identity and transaction signing. The CLI stores it securely in your OS keyring (macOS Keychain / Linux Secret Service) — it's never saved to disk in plaintext.

Option A: If you already have a private key (e.g. from MetaMask):

$ ecloud auth login
? Enter private key: 0x7a9f...c3e1
✓ Private key stored securely in OS keyring

Option B: Generate a brand new key:

$ ecloud auth generate --store
✓ New private key generated and stored in OS keyring

Confirm you're authenticated:

$ ecloud auth whoami
Authenticated as 0x1002...976d2
💡 This address is your deployer identity. You'll use it to manage all your EigenCompute apps.

Step 3 — Set Up Billing

EigenCompute requires an active billing subscription before you can deploy. This is a one-time setup — you won't need to do this again for future deploys.

ecloud billing subscribe

The CLI will walk you through the payment setup. Check your billing status anytime:

ecloud billing status

Step 4 — Build Your App

Compile your application. Make sure it builds cleanly before containerizing.

$ npm run build
> tsc
Compiling TypeScript to dist/ ...
✓ Build complete — 0 errors

Step 5 — Write Your Dockerfile

Your app needs a Dockerfile so EigenCompute knows how to build and run it. If you've never written one, here's a minimal example for a Node.js app:

FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build
EXPOSE 3000
USER root
CMD ["node", "dist/index.js"]
⚠️ Your app must run as root — this is required by EigenCompute's TEE environment. Make sure you have USER root in your Dockerfile.

You can also scaffold a project with the correct Dockerfile using ecloud compute app create --name myapp --language typescript. Supported languages: typescript, python, golang, rust.

Step 6 — Build & Push Docker Image

Build your Docker image and push it to Docker Hub. The image must be linux/amd64 because EigenCompute runs on Intel TDX hardware — even if you're developing on an ARM Mac.

First, make sure you're logged into Docker Hub:

docker login

Then build and push:

docker buildx build --platform linux/amd64 --no-cache \
  -t yourdockerhub/yourapp:v1.0.0 --push .
⚠️ Do NOT skip --platform linux/amd64. If you're on an Apple Silicon Mac, Docker will default to ARM — which will fail on EigenCompute.

Step 7 — Prepare Your .env File

Create a .env file with your app's runtime secrets and configuration. This file gets encrypted and injected into the TEE at deploy time — your secrets never touch disk unencrypted on the host machine.

PORT=3000
DATABASE_URL=postgres://user:pass@host:5432/db
API_KEY=sk-your-api-key
SECRET_KEY=your-secret

Step 8 — Deploy to EigenCompute

This is the main event. Run the deploy command — the CLI will interactively prompt you for each configuration option, one at a time. You don't need to memorize any flags.

Step 9 — Verify Your Deployment

Your app is deployed — now make sure it's actually running and reachable.

Check app status:

ecloud compute app info --watch

This shows your app's status, public IP, and instance details. The --watch flag auto-refreshes every 5 seconds so you can see the app boot up in real time.

Stream logs:

ecloud compute app logs --watch

See your app's stdout/stderr live — useful for debugging startup issues.

Health check from your terminal:

$ curl http://<YOUR-PUBLIC-IP>:3000/health
{"status":"ok","tee":"active","version":"1.0.0"}

Replace <YOUR-PUBLIC-IP> with the IP shown in ecloud compute app info.

✅ If you see a JSON response, your app is live inside an Intel TDX enclave. Congrats!

Upgrading (Future Deploys)

When you push a new version, build a new image tag and use upgrade instead of deploy:

# 1. Build & push new image
docker buildx build --platform linux/amd64 --no-cache \
  -t yourdockerhub/yourapp:v1.0.1 --push .

# 2. Upgrade the running app
ecloud compute app upgrade <APP-ID> \
  --image-ref yourdockerhub/yourapp:v1.0.1 \
  --env-file .env

Important Notes

  • Docker images must be linux/amd64 — ARM images will not work on Intel TDX
  • Your app must run as root inside the container (TEE requirement)
  • Environment variables are encrypted and injected at runtime — they never touch disk unencrypted
  • TEE provides hardware-level isolation via Intel TDX — your code and data are protected even from the host machine operator
  • A KMS signing key is available inside the TEE at /usr/local/bin/kms-signing-public-key.pem for cryptographic attestation
  • Use ecloud compute app deploy for first-time deploys, ecloud compute app upgrade for updates
